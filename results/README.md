# Results

All files here are generated by `python -m src.evaluate` and
`python -m src.export_embedded`. No performance figure is hand-drawn or
illustrative.

## Metrics

| File | Contents |
|---|---|
| `metrics/metrics.json` | Full CV, validation, test, baseline, calibration and runtime payload |
| `metrics/classification_report_test.txt` | Per-class precision/recall/F1 and test confusion matrix |
| `metrics/classification_report_validation.txt` | Validation report |
| `metrics/model_comparison.csv` | Candidate CV/validation scores and serialized sizes |
| `metrics/model_selection.md` | Selection protocol and candidate table |
| `metrics/cv_fold_metrics.csv` | Per-fold CV metrics |
| `metrics/confusion_matrix_train_cv.csv` | Out-of-fold CV confusion matrix |
| `metrics/confusion_matrix_validation.csv` | Validation confusion matrix |
| `metrics/confusion_matrix_test.csv` | Test confusion matrix |
| `metrics/per_session_test_metrics.csv` | Accuracy, macro F1 and recalls per test session |
| `metrics/critical_errors_test.csv` | Test errors, including Danger→Normal cases |
| `metrics/calibration_bins_test.csv` | Top-label calibration bins |
| `metrics/baseline_comparison.json` | Threshold baseline and McNemar result |
| `metrics/embedded_parity.txt` | Host C/Python parity log |
| `metrics/evaluation_summary.md` | Human-readable summary |

## Regenerate

```bash
python -m src.train
python -m src.evaluate
python -m src.export_embedded
```

`src.evaluate` needs the artifacts from `src.train`. `src.export_embedded` needs
`metrics.json` and the final model.
